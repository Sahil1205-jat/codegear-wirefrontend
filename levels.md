# Code Gear & Wear: Gamified Curriculum (Micro-Progression)

To ensure mastery through repetition (practice makes perfect), the curriculum is broken down into **Micro-Progressions**. Each Phase contains ~45 levels that slowly ramp up in difficulty, ensuring every single sub-concept is mastered before moving on.

---

## Phase 1: Core Systems (45 Levels)
**Topic:** Standard Output, Primitive Data Types, Variables, and Basic Math.

### Sub-Phase 1A: Standard Output (Levels 1-10)
* **Level 1: System Boot:** Print exactly `Hello Machine`
* **Level 2: Diagnostic Ping:** Print exactly `Ping...`
* **Level 3: Multi-line Output:** Print `Sys` on one line and `Init` on the next.
* **Level 4: Character Escapes:** Print a string containing quotes: `The system said "Hello"`
* **Level 5: Raw Integers:** Print the raw number `404` (not as a string).
* **Level 6: Raw Decimals:** Print the raw float `3.14159`
* **Level 7: Boolean Output:** Print the result of `true` or `1` depending on language.
* **Level 8: Special Characters:** Print a file path `C:\sys\config` (testing escape characters).
* **Level 9: Whitespace Formatting:** Print `A B C` with tabs between them.
* **Level 10: End of Output Test:** A final test combining strings, numbers, and newlines.

### Sub-Phase 1B: Variable Allocation (Levels 11-25)
* **Level 11: Integer Allocation:** Declare an int `x = 10` and print it.
* **Level 12: Re-allocation:** Declare `x = 5`, change it to `10`, print it.
* **Level 13: Floating Point Config:** Declare a float `voltage = 5.5` and print it.
* **Level 14: Character Buffers:** Declare a char `grade = 'A'` and print it.
* **Level 15: String Pointers:** Declare a string `status = "ONLINE"` and print it.
* **Level 16: Constant Memory:** Declare a constant variable and print it.
* **Level 17: Multiple Declarations:** Declare two integers on one line and print the second one.
* **Level 18: Variable Swapping (Basic):** Use a temp variable to swap `a` and `b`.
* **Level 19: Concatenation:** Combine a string variable and a string literal and print them.
* **Level 20: Interpolation:** Inject an integer variable into a string.
* **Level 21-25:** Repetitive practice with edge cases (uninitialized variables, type mixing).

### Sub-Phase 1C: The Arithmetic Logic Unit (Levels 26-45)
* **Level 26: Basic Addition:** `a + b`
* **Level 27: Basic Subtraction:** `a - b`
* **Level 28: Multiplication:** `a * b`
* **Level 29: Integer Division:** `10 / 3` (understanding truncation)
* **Level 30: Floating Point Division:** `10.0 / 3.0`
* **Level 31: Modulo Operations:** `10 % 3`
* **Level 32: Even or Odd:** Using modulo to print `0` or `1`.
* **Level 33: Increment Operators:** `x++` vs `++x`
* **Level 34: Decrement Operators:** `x--`
* **Level 35: Compound Assignment:** `x += 5`
* **Level 36: Order of Operations (PEMDAS):** `(a + b) * c`
* **Level 37: Negative Numbers:** Math with `-5`
* **Level 38: Absolute Values:** Math crossing 0.
* **Level 39-44:** Complex algebraic equations simulating hardware physics (e.g., Ohms Law: `V = I * R`).
* **Level 45: Phase 1 Boss Fight:** A massive calculation requiring variables, strings, and correct PEMDAS to unlock Phase 2.
